# emilverkama.fi

Source for my personal academic page, live at **[emilverkama.fi](https://emilverkama.fi)**.

It is a single hand-written `index.html` — no framework, no build step, no dependencies beyond [KaTeX](https://katex.org), loaded from a CDN to typeset the mathematics. Styling is a `<style>` block at the top of the same file. Served by GitHub Pages.

```
index.html    the entire site
photo.jpg     portrait
favicon.svg   tab icon
CNAME         custom domain for GitHub Pages
```

Feel free to borrow the layout if it's useful to you. The text and photograph are mine.
